# Support

## Security issues

For vulnerabilities or sensitive security issues, do not open a public issue.

Follow SECURITY.md.

## Repository and workflow questions

For normal repository questions, design questions, and tranche-scoped discussion:
- use GitHub issues or pull request discussion on the relevant branch or PR
- keep questions scoped to the contract, validator, workflow, or docs surface involved

## Good issue reports

Please include:
- branch or commit
- affected file(s)
- expected behavior
- actual behavior
- reproducer or exact command sequence, if applicable

## Maintainer guidance

This repository evolves through semantic and documentation tranches. If a question is about future design rather than a defect, anchor it to the relevant spec under docs/specs/.
