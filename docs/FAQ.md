# FAQ

## What is Policy Fabric?

Policy Fabric is a governed platform for authoring, validating, packaging, and reviewing data-protection policy as code.

## What is this repository?

This repository is the Policy Fabric Control Repository: the source-of-truth repo for contracts, examples, governance surfaces, workflow surfaces, and generated control artifacts.

## Is this repository MIT licensed?

Yes. See LICENSE.

## How do we report vulnerabilities?

Do not use public issues for vulnerabilities. Follow SECURITY.md.

## Why are generated reports committed?

Because this repository treats validation and governance outputs as part of the control surface, not as disposable build byproducts.

## What is the relationship to AgentPlane?

Policy Fabric remains the product and contract/governance model. AgentPlane is the integrated repo-native workflow layer around this repository.

## Is this production software?

This repository is usable now, but the platform is still evolving through semantic tranches and docs tranches. Expect active refinement.

## Where should normal questions go?

Use GitHub issues or PR discussion for non-sensitive questions. Use SUPPORT.md for the support posture.
