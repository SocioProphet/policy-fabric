# Turn 03 — Branch audit and branch-safety layer

We audited the repository topology before further integration work. The snapshot has a clean linear history on `main`, no remotes, and no branch divergence, but that simplicity now creates its own risk because recent changes have all landed directly on `main`.

This turn adds a branch policy contract, a branch-audit script, baseline tags, and explicit recommended `work/` branches so the next risky changes can happen off the protected baseline.
